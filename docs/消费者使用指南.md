# 元境 · 消费者使用指南（小白版）

> 一句话：**元境 = 装在手机里的 AI 助手，能对话、能帮你执行终端命令、还能离线跑小模型。**

---

## 一、安装

1. 拿到 `IQCode-debug.apk`，点开安装（首次需允许"安装未知来源应用"）。
2. 打开"元境"，按提示允许**悬浮球权限**（后台气泡）和**通知权限**。
3. 首页顶部显示 **对话 / 终端** 两个 Tab，右上角是 token 用量（如 14.2k/128k）。

---

## 二、界面逐块说明（截图一张张讲）

### 截图 1 · 本地模型库（真实截图）

![本地模型库](截图-本地模型库.jpg)

这张图是 **设置 → 本地模型库** 面板，从上到下：

| 区域 | 是什么 | 大白话 |
|---|---|---|
| ⚠ 缺少 llama-server | 引擎提示 | 想让手机离线跑 AI，得先装一个小引擎。在 Termux 输入 `pkg install llama.cpp`，或者下载 arm64 版 `llama-server` 放进 `~/.iq/bin`。装好这条就变绿 ✓ |
| 设备档位 HIGH · 内存 15269MB（可用 4764MB） | 你手机的体检报告 | 元境自动看你手机有多大内存、还剩多少可用，决定推荐多大的模型 |
| 本机推荐：qwen2.5-coder-0.5b-q4 | 推荐结果 | 根据你的可用内存，推荐"刚好能流畅跑"的最小模型。你手机虽然总内存大，但可用只有 4.7GB，所以推荐最小的 0.5b |
| 模型列表（0.5b → 14b） | 模型超市 | 每个都标了：文件大小、需要多少内存、上下文长度、是否支持工具调用。**选模型看"需内存"这一列，不要超过你的可用内存** |
| 下载按钮 | 下载动作 | 点一下就开始下载，再点变"删除"。下载有断点续传，断了会接着下 |

**模型选择口诀**：
- 只想离线写代码/问答 → 0.5b 或 1.5b
- 要它自动操作工具 → 选"支持工具"的（3b 起）
- 手机内存小 → 千万别点 7b/14b，会卡死
- **现在列表里每个模型都带标签**：天蓝"推荐"＝最适合你；绿"可运行"＝能跑但偏大；红"内存不足"＝跑不动，别下

### 其他界面（装好后我会补截图，先讲清楚）

#### 2. 对话界面（首页）
- 底部输入框打字提问，像微信聊天一样。
- 右上角 `/` 开头的指令：输入 `/help` 看全部指令，`/config` 快速改设置。
- 每轮回答显示 token 消耗（右上角），用得多会提示压缩上下文（防止越聊越慢）。

#### 3. 终端界面
- 真的 Linux 终端（Termux 内核），能执行 `ls`、`pip install` 等命令。
- 元境会自动在这里执行它认为需要的命令，**高风险命令会弹权限确认**，你同意才执行。

#### 4. 设置页（点右上角 ⚙ 或输入 /config）
| 设置项 | 大白话 | 建议 |
|---|---|---|
| 主题模式 | 换皮肤（暖墨/暖纸/深蓝科技） | 默认科技风 |
| 推理强度 | 模型多想几步再回答 | 慢但更准，卡就调低 |
| 权限模式 | 工具执行要不要问你 | 建议"询问" |
| 本地小模型兜底 | 断网/云端失败时用本地模型顶上 | 打开 |
| 联网搜索 | 回答前先搜网 | 打开 |
| 上下文窗口 | 记住多少轮对话 | 默认即可 |

> 每个设置项旁边有 **"?"** 小按钮，点开就是大白话解释，不用查文档。

#### 5. 关于页（设置里"关于 元境"）
- 品牌"元境"、作者 zihan8023、GitHub 链接。
- **检查更新**：点一下自动去 GitHub 查最新版，有新版弹窗给你下载页。

#### 6. 悬浮球（后台气泡）
- 切到别的 App，元境的小球还飘着，点它快速唤起对话。
- 通知栏有"元境后台保活"常驻通知（别关，关了它就"睡着了"）。

## 三、常见问题

| 问题 | 答案 |
|---|---|
| 下载模型失败/卡住 | 断点续传会自动接着下；失败再点一次下载 |
| 本地模型回答很笨 | 正常，0.5b 是最小模型；要聪明就换大模型（看你内存） |
| 想卸载干净 | 设置 → 应用 → 元境 → 卸载；悬浮球权限记得一起关 |
| 更新检查提示没发布 | 开发者还没把新版发到 GitHub Release，等发布即可 |
