## 一、项目是什么

**元境** 是一个运行在 Android 手机上的 **AI 智能体 App**（原名 IQ Code，开源项目）。它把"AI 对话 + 终端命令 + 工具调用"合在一起：你打字提需求，它调用大模型思考，然后自动执行工具（执行命令、读写文件等）并把结果继续喂回模型，形成"思考 → 执行 → 再思考"的循环。

**架构（两层）**：

| 层 | 包名 | 职责 |
|---|---|---|
| 智能体核心 | `com.termux.app.iqcode` | 纯 Java 的 Agent 引擎：`IQCodeEngine` 单线程主循环（消息排队 → 调模型 → 流式输出 → 工具成批执行 → 自动压缩上下文） |
| UI 与系统集成 | `com.iqge` | 自绘 UI（无 XML 布局，全部 Java 代码画界面）、`MainActivity`（7,500+ 行）、悬浮球、后台保活、文件 Provider |

**模块**：`app`（主工程）＋ `Bcore` / `black-reflection` / `compiler`（编译期与反射辅助）。

## 三、本地模型功能（离线兜底）

| 文件 | 职责 |
|---|---|
| `local/DeviceProfile.java` | 探测设备档位：CPU 核数、总/可用内存、温度（`ACTION_BATTERY_CHANGED` 公开 API）、档位 LOW/MID/HIGH |
| `local/LocalModelManager.java` | 模型注册表（5 档 qwen2.5-coder：0.5b/1.5b/3b/7b/14b）、`recommend(dp)` 按设备画像推荐、断点续传下载 + 白名单校验、llama-server 缺失检测 |
| `local/LocalModelProvider.java` | 本地模型与引擎对接（llama-server 进程管理） |
| `local/RouterProvider.java` | 路由策略：云端 / 本地 分流（auto / local-first / cloud-first） |
| `local/SessionConfig.java` | 会话配置（上下文窗口等） |

**推荐标签（本次新增）**：模型列表每行按"可用内存"打标签
- `需内存 ≤ 可用内存 × 0.7` → **推荐**（天蓝）
- `需内存 ≤ 可用内存` → **可运行**（绿）
- 否则 → **内存不足**（红）

**UI 面板**：设置 → 本地模型库。显示引擎状态、设备档位+内存、推荐模型、5 档模型下载/删除。

**运行时依赖**：`llama-server`（Termux 执行 `pkg install llama.cpp`，或放 arm64 二进制到 `~/.iq/bin`）。

## 四、构建方法

```
$env:JAVA_HOME='E:\Dev\jdk-17.0.20.1+1'
$env:ANDROID_HOME='E:\Android\Sdk'
$env:GRADLE_USER_HOME='E:\Dev\gradle-cache'
$env:PATH="$env:JAVA_HOME\bin;$env:PATH"
cd E:\Dev\IQ-Code-Android
.\gradlew.bat --no-daemon assembleDebug
```

- 产物：`app\build\outputs\apk\debug\IQCode-debug.apk`（约 32.3MB）
- 签名：`app\signing\iqge-local-dev.jks`（debug 用）
- Release 版已开 R8 混淆裁剪（`minifyEnabled true`）：把方法名混淆成短码 + 裁剪无用代码 → 包更小、更难被反编译

## 五、已知技术决策

| 决策 | 原因 |
|---|---|
| `com.iqge` 包名保留 | 整体重命名 package 风险过高（反射/Provider/manifest 多处联动） |
| 更新检查暂指 `zihan8023/xxm` | 用户现有公开仓库；后续可改常量指向"元境"专用仓库 |
| UI 全部 Java 自绘 | 无 XML 布局，主题令牌集中在 `applyUiPalette()`，改色板即全局换装 |
